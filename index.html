iPhone widget

  1. Install the free app Scriptable from the App Store.
  2. On your iPhone, tap Copy widget script below, then in Scriptable tap +, paste, and name it Tramboard.
  3. Add a Scriptable widget to your Home Screen, long-press it, tap Edit Widget, pick the Tramboard script, and set Parameter to 8591066,8591323.
  4. Optional: to make it blend into your wallpaper, screenshot an empty Home Screen page, crop it in Photos to where the widget sits, then run the script in Scriptable and choose Set background from photo. Without a photo it follows light and dark mode.
